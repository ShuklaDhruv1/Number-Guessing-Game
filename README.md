# 🎮 Number Guessing Game

A simple console-based Number Guessing Game made using Java.

## 📌 About

The computer generates a random number between 1 and 100.
The player has to guess the number.

The game gives hints:
- Too Low
- Too High
- Correct

## 🛠️ Technologies Used

- Java
- Scanner
- Random
- Loops
- Conditional Statements

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code or IntelliJ IDEA.
3. Compile the Java file.
4. Run the program.

## 🎯 Learning Purpose

This project was created to practice basic Java programming concepts.
