## 🎮 About The Game

> **The computer has chosen a secret number. Can you find it?**

**Number Guessing Game** is a beginner-friendly Java console game where the computer randomly selects a number between **1 and 100**.

Your mission is simple:

```text
🎯 Guess the Number
⬇
💡 Get a Hint
⬇
🔁 Try Again
⬇
🏆 Find the Secret Number
```

---

## ⚡ Features

* 🎲 Random number generation
* 🎯 Number range from 1–100
* 🔥 Too High / Too Low hints
* 🏆 Attempt counter
* 🖥️ Simple console interface
* ⚡ Beginner-friendly Java code

## 🚀 Run The Project

### 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Number-Guessing-Game.git
```

### 2️⃣ Open the project

Open the project in **VS Code**, **IntelliJ IDEA**, or any Java IDE.

### 3️⃣ Compile

```bash
javac NumberGuessingGame.java
```

### 4️⃣ Run

```bash
java NumberGuessingGame
```
